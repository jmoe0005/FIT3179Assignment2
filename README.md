# Holidays at Home: Domestic Tourism in Australia

FIT3179 Data Visualisation 2. Open `index.html` via GitHub Pages.

- `js/*.vg.json`: Vega-Lite specs (one per chart) and `aus_states.topojson` (state boundaries)
- `data/trips_state_year.csv`: overnight trips, nights and spend by destination state, 2019 and 2021 to 2024 (TRA National Visitor Survey, Table 1a)
- `data/trips_purpose_year.csv`: overnight trips and spend by reason for trip (TRA NVS Table 2a)
- `data/national_year.csv`: national totals; 2025 is the sum of the four 2025 quarters from TRA Domestic Tourism Statistics (new method)
- `data/state_population.csv`: ABS estimated resident population, March 2026, plus label positions
